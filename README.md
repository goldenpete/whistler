# whistler

## Docs Editor Features

Whistler's Docs Editor provides a rich text editing experience with various formatting options. This guide covers all available features and how to use them.

### Basic Formatting

- **Bold**: Click the Bold button (or press `Ctrl+B`) to make selected text bold.
- **Italic**: Click the Italic button (or press `Ctrl+I`) to italicize selected text.

### Text Formatting Options

#### Text Size Changer

Adjust the size of your text using the Text Size dropdown in the toolbar:

1. Select the text you want to resize
2. Click the Text Size dropdown button in the toolbar
3. Choose from available size options (Small, Normal, Large, Extra Large)
4. The selected text will be resized accordingly

**Note**: Text size can be applied to any selected text, regardless of heading style.

#### Underline

Add underlines to emphasize text:

1. Select the text you want to underline
2. Click the Underline button in the toolbar (or press `Ctrl+U`)
3. The selected text will be underlined

**Tip**: To remove underline, select the underlined text and click the Underline button again.

#### Text Color

Change the color of your text:

1. Select the text you want to colorize
2. Click the Text Color button in the toolbar
3. A color picker will appear
4. Choose your desired color from the palette or use the advanced color picker for custom colors
5. Click "Apply" to set the color

**Note**: Text color is applied to the selected text and will persist until you change it again.

#### Highlighter

Highlight text with a background color:

1. Select the text you want to highlight
2. Click the Highlighter button in the toolbar
3. A color picker will appear showing highlight colors
4. Choose your preferred highlight color (typically yellow, but custom colors are available)
5. Click "Apply" to highlight the text

**Tip**: Highlighting is useful for marking important sections or creating visual emphasis in your documents.

### Lists

Create organized lists in your documents:

#### Bulleted Lists
1. Place your cursor where you want the list to begin
2. Click the List dropdown button
3. Select "Bulleted List"
4. Start typing - each new line will automatically become a bullet point
5. Press `Enter` twice to exit the list format

#### Numbered Lists
1. Place your cursor where you want the list to begin
2. Click the List dropdown button
3. Select "Numbered List"
4. Start typing - each new line will automatically be numbered
5. Press `Enter` twice to exit the list format

#### Checkboxes (Task Lists)
1. Place your cursor where you want the checkbox list to begin
2. Click the List dropdown button
3. Select "Checkbox List" (or "Task List")
4. Start typing - each new line will automatically become a checkbox item
5. Click the checkbox to mark items as complete
6. Press `Enter` twice to exit the checkbox format

**Note**: Checkboxes can be toggled by clicking directly on them while editing your document.

### Inserting Images

Insert images into your documents using Catbox links:

1. **Upload your image to Catbox first**:
   - Go to [catbox.moe](https://catbox.moe/) in a new tab
   - Upload your image file
   - Copy the direct image link provided by Catbox (e.g., `https://files.catbox.moe/xxxxx.png`)

2. **Insert the image in your document**:
   - Place your cursor where you want the image to appear
   - Click the Insert Image button in the toolbar
   - A dialog will appear prompting for a Catbox URL
   - Paste your Catbox link into the input field
   - Click "Insert" to add the image to your document

**Important**: 
- Only Catbox links are accepted for image insertion
- Copy-pasting regular images directly into the document is not supported
- This ensures image stability and prevents local file references that may break

### Headings

Organize your document with headings:

1. Select the text you want to make a heading (or place your cursor in a paragraph)
2. Click the Heading dropdown button
3. Choose from:
   - **H1 (Title)**: Largest heading, typically used for document titles
   - **H2 (Subtitle)**: Second-level heading
   - **H3 (Heading)**: Third-level heading
   - **H4 (Subheading)**: Fourth-level heading
   - **H5 (Section)**: Fifth-level heading
   - **H6 (Subsection)**: Smallest heading
   - **P (Body)**: Regular paragraph text

### Links

Insert both external and internal links:

1. Select the text you want to link (or place your cursor where you want the link)
2. Click the Link button (or press `Ctrl+K`)
3. Choose between:
   - **External URL**: Enter a web address (e.g., `https://example.com`)
   - **Internal Link**: Link to files, collections, or timestamps within Whistler
4. Click "Insert Link" to create the link

**Tip**: When your cursor is inside a link, a floating pill will appear allowing you to edit, open, or delete the link.

### Undo/Redo

- **Undo**: Click the Undo button (or press `Ctrl+Z`) to reverse your last action
- **Redo**: Click the Redo button (or press `Ctrl+Y`) to redo an undone action

### Tips

- All formatting options work with text selection - highlight the text you want to format before applying styles
- You can combine multiple formatting options (e.g., bold + italic + underline + color)
- The toolbar buttons show an active state when your cursor is positioned in text with that formatting
- Your document is automatically saved as you type
